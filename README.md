# Snake game

A simple and fun snake game built using pure HTML, CSS and JavaScript.

## How to play:
### Desktop:
Use arrow keys:
- ⬆️ Move up
- ⬇️ Move down
- ⬅️ Move left
- ➡️ Move right
### Mobile:
Use the on-screen arrow buttons to control the snake

Try this game [here](https://quocanhxemer.github.io/snake-game/). Hope you enjoy.
